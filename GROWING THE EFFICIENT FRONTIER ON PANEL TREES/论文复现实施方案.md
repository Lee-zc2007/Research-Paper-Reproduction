# P-Tree 论文复现实施方案

更新日期：2026-10-29

论文：Growing the Efficient Frontier on Panel Trees

## 1. 目标与边界

使用 CSMAR 中国 A 股数据复现论文的主要方法和实验流程。先实现单棵 P-Tree，再扩展至多树及样本外评价。不要求完整覆盖原文 61 项特征，也不以复刻美国样本的具体数值为成功标准。

现有原始数据支持约 40 项核心候选特征；这个数量不代表已完成计算或严格原文口径验证。最终使用哪些特征，应由定义核对、有效覆盖率和质量检查决定。

项目目录：`GROWING THE EFFICIENT FRONTIER ON PANEL TREES/`

- 作者代码：`TreeFactor/`
- 原始数据：`raw_data/`
- 最近数据复核：`audit/复现能力复核.md`
- 日行情核验结果：`audit/daily_audit.json`
- 可重复执行的核验脚本：`audit/check_daily.py`

本方案仅规划后续工作，不表示下面的实验或产物已经完成。

## 2. 当前进度与样本安排

已收集月行情、日行情、三张财务报表、财报披露日期、公司资料、无风险利率、日三因子及月五因子。

最近一次核验确认：1995—2020 年日行情未发现整市场交易日期缺口；当时仍缺 2021-01-04 至 2021-10-28 的 197 个市场交易日。用户正在补充该部分，下载完成后重新核验，不能将“正在下载”记为“已通过核验”。

先使用截至 2020-12 的样本开展开发和实验，2021 年数据核验后再延长。样本起点根据财务季报覆盖、公告日期质量及滚动窗口预热期确定，不预先承诺所有特征从同一早期年份都可用。

保留更早的原始历史用于计算特征。最长动量窗口需要至少 60 个月历史；季度盈余意外等指标另需足够的季度历史。

## 3. 阶段一：原样跑通作者 demo

### 工作

1. 阅读 `TreeFactor/README.md`、依赖配置和 demo 启动脚本。
2. 原样运行一个 demo，不修改算法、参数或模拟数据生成方式。
3. 保存运行命令、依赖版本、随机种子、日志和原始输出。
4. 梳理 demo 的输入、训练调用、预测调用和结果提取。

### 必须回答的问题

- 每一行数据代表股票、月份，还是已经形成的组合？
- 输入是长面板还是矩阵？排序和索引有哪些要求？
- 特征、收益、市值或其他权重分别对应哪个参数？
- 收益是否已经向前移动一期，是否已扣除无风险利率？
- 训练、验证和测试的划分发生在哪里？
- 输出包含哪些树结构、组合权重和收益序列？

### 产物与验收

产物：demo 运行日志、输入输出说明、主要函数调用链。

验收：原始 demo 可以稳定运行；能够解释输入输出含义，并在固定种子及相同环境下复查结果。不能仅以“程序没有报错”作为算法正确的证明。

## 4. 阶段二：理解并验证核心算法

从 demo 调用入口沿函数链阅读，不从全部 C++ 源文件逐行开始。

重点追踪：

> 候选特征切分 → 叶节点内股票组合 → 组合收益序列 → 分裂目标函数 → 选择分裂并更新树 → 测试期应用规则

核对以下设置与论文的关系：

- 候选切分点与特征变换。
- 叶节点内的股票权重、叶节点之间的组合权重。
- 最小叶节点规模、最大树规模、停止条件。
- 目标函数、约束与正则化设置。
- 训练期估计的量，以及测试期允许更新的量。
- 不平衡面板和缺失观测如何处理。

建立一个小型人工或模拟样本，独立计算一次叶节点收益和候选分裂目标，与代码输出比较。

验收：能解释为何选中某次分裂；独立计算与程序结果在合理数值误差范围内一致。

## 5. 阶段三：固定实验口径

在处理正式数据前建立配置表。以下项目必须明确，原论文设置与中国市场调整分别记录。

| 项目 | 初始安排或待定事项 |
|---|---|
| 市场 | 中国 A 股；明确交易所和板块范围，不混入不同币种的 B 股 |
| 样本时间 | 初版截至 2020-12；起点依数据覆盖确定 |
| 模型 | 单棵 P-Tree 起步 |
| 特征 | 先 5—10 项易核验指标，再扩展核心候选集 |
| 股票筛选 | 明确上市历史、ST、金融业等规则；不能用当前状态回溯筛选 |
| 收益口径 | 明确含分红再投资收益与超额收益的使用位置 |
| 权重 | 明确总市值或流通市值；区分股票权重与组合配置权重 |
| 样本划分 | 按时间划分训练、验证、测试；具体日期在覆盖检查后固定 |
| 更新方式 | 固定训练期、滚动或扩展窗口须明确；优先与目标论文实验对应 |
| 基准 | 同可投资样本的等权和市值加权组合；另做因子评价 |
| 随机性 | 记录种子、代码版本和配置 |

验收：不存在影响结果的隐含选择；测试数据不参与特征选择和参数选择。

## 6. 阶段四：清洗数据并构造股票—月份面板

### 6.1 原始数据核验

- 核对文件清单、字段、实际日期范围、记录数及主键重复。
- 检查日行情批次之间的空缺和重叠。
- 结合市场日期和月行情检查覆盖，但不把市场级完整等同于每只股票每日完整。
- 保留原始 CSV 和字段说明，不覆盖原始文件。

### 6.2 财务数据处理

- 统一合并报表与母公司报表口径，剔除不适合作为独立报告期的期初行。
- 区分累计季报、单季值、年度值和滚动年度值，按特征定义转换。
- 使用 `IAR_Rept.Annodt` 对齐信息公开时间。
- `DeclareDate` 是会计差错更正公告日，不能代替原始披露日。
- 公告日匹配不能自动消除修订后财报数值的前视偏差；记录版本信息的局限。
- 对缺失或不完整公告日期制定明确规则，不凭空填为已知日期。

### 6.3 行情与利率处理

- 核对价格、市值、成交金额和股数单位，尤其是千元与元的换算。
- 保留退市股票历史，明确停牌、不可交易和缺失收益的处理。
- 不把缺失停牌月份自动填成零收益。
- `Trdsta` 可识别 ST 及其历史变种；不应简单把所有非 1 状态都认定为 ST。
- FF 市场风险溢价不等于市场原始收益率；统一回归使用的无风险基准。
- 单独无风险利率表与因子内置利率可能口径不同，需核对单位和基准。

### 6.4 特征计算与标签对齐

最终每一行对应一个股票—月份观测：

| 股票代码 | 月份 t | 截至 t 可知的特征 X_t | t 月末市值 | t+1 月收益 |
|---|---|---|---|---|

保留特征所用财报期、公告日期或窗口截止日等审计信息。明确交易时点，避免月末收盘后才公开的信息被用于同一收盘价成交。

按定义执行极值处理、缺失处理和变换。横截面排名只能使用当时可得的信息；需要拟合的预处理参数不得使用未来数据。

验收：面板主键唯一，标签仅向前对齐一次；随机抽取若干股票月份可追溯并独立复算特征；输出各特征按年份的覆盖率和缺失率。

## 7. 核心候选特征清单

以下 40 项按主要原始字段支持列入候选。原文 Table A.1 主要是简要描述，不能替代公式核验；实施时为每项建立“定义—公式—源字段—单位—滞后—窗口—差异”的字典。

| 类别 | 数量 | 候选特征 |
|---|---:|---|
| 规模与价值 | 8 | ME、BM、CASH、CFP、EP、LEV、SGR、SP |
| 动量与盈余信息 | 11 | MOM1M、MOM6M、MOM12M、MOM36M、MOM60M、NINCR、RSUP、SUE、CHTX、SEAS1A、ABR |
| 盈利与投资 | 11 | ACC、AGR、ATO、CHPM、GMA、LGR、OP、PCTACC、PM、ROA、ROE |
| 交易与风险 | 10 | BETA、ILL、MAXRET、DOLVOL、RVARCAPM、RVARFF3、SVAR、STDDOLVOL、STDTURN、TURN |

第一版可从 ME、BM、AGR、ROA、MOM1M、MOM12M、SVAR、TURN 等少量特征入手。选择依据是可核验性与维度覆盖，不通过测试期收益反向挑选。

ALM、CASHDEBT、CHCSHO、CINVEST、DY、GRLTNOA、NI、NOA、PS、RNA、ZEROTRADE 暂列额外候选，核对定义和记录机制后再决定是否加入。

不为凑齐 61 项强行使用当前行业替代历史行业，或用高低价估计冒充真实买卖价差。研发费用字段仅有较晚年份覆盖，也不自动等价于全部研发投入。

## 8. 阶段五：接入中国数据并验证小规模模型

1. 用较短时期、少量特征和浅树生成最小可运行版本。
2. 按作者接口转换排序、索引和数据形状。
3. 检查每只符合条件的股票在每个时期的叶节点归属。
4. 独立复算叶节点收益、权重约束和最终组合收益。
5. 核对训练期与测试期边界，确保分裂和参数选择不使用测试收益。
6. 检查缺失数据是否意外使可投资样本或不同策略样本发生变化。

验收：从原始数据到组合收益的全链条可重复、可追踪、可复算。收益高低不作为此阶段的验收标准。

## 9. 阶段六：正式实验与稳健性检验

在小规模验证通过后，扩大样本和特征集，按目标实验逐步加入多树设置。

主结果记录：

- 样本外收益、波动率、Sharpe 比率和最大回撤。
- 与同样本等权、市值加权基准的对比。
- 因子调整后的表现及所采用的统计推断方法。
- 换手率、交易成本敏感性和交易可行性。
- 树结构、分裂特征、叶节点组成及其经济含义。

稳健性检验包括：不同时期、合理的样本筛选、权重口径、树规模、特征子集及随机种子。预先规定主要设置，避免对测试集反复调参。

每张结果表都标明样本、配置、是否样本外、收益是否扣成本，以及与原文的差异。

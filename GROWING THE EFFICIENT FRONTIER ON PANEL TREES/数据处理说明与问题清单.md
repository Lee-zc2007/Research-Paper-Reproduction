### 生效处理规则

1. 资产有限且为正、负债和现金有限且非负、权益有限时，将短期借款、长期借款、应付债券空白按结构性零处理。其余报表缺失保持缺失。该假设未经数据供应商确认，不能宣称空白已证实等于零。
2. CASHDEBT仍要求有息负债大于零。LGR仍要求12个月前长期借款加债券大于零。零分母保持缺失，不通过填零伪造比率。
3. 季度计算先补齐每只股票的季度日历，再按8个日历季度滚动，最少4个有效观察。公告记录按季度及Reptyp对应筛选。插入的空季度不参与公告日as-of。
4. BASPREAD改为当前日与前一交易观测配对，消除原先shift(-1)使用下一日价格的问题。文件批次边界不跨文件配对，边界覆盖限制仍存在。
5. ABR要求完整三个交易日，按事件窗口最后交易日所属月记录可用时点，之后由主表统一滞后一月。仍为稀疏事件特征，不进入覆盖候选；批次边界不完整窗口舍弃。
6. 动量保留完整窗口规则，不把停牌缺月擅自当作零收益。财务增长保留12个月历史要求。NI空白保持缺失。
7. audit_stage4按股票与报告期保留最后一次公告，与生产规则对齐。
8. 从原始数据重新生成L1，使用--refresh刷新年频、季频、日频及日频汇总缓存，再导出排名输入与RDS。

## 3. 处理链路

```
raw_data/
   │
   ├─ L1  asof_reports.py         → data/asof_annual.csv     915,674 行 × 49 列
   │       还原"某月末当时能看到的最新年报"
   │
   ├─ L2  build_monthly_panel.py  → data/panel_v1.csv        740,221 行 × 62 列
   │       选样 + 超额收益 + 缩尾 + t−1 对齐 + 48 特征
   │       └ 特征模块：features_annual.py / features_quarterly.py / features_daily.py
   │
   ├─ L3  panel_export.py         → data/model_input_v1.csv  740,221 行 × 54 列
   │       截面排名 → [−1,1]、缺失填 0、0 基索引
   │
   └─ R   panel_to_r_input.R      → data/r_input_v1.rds      13 个入参
            拆参数 + 10 项断言（暂未训练）
```

### 3.1 L1：as-of 事实表

| 规则 | 做法 | 依据 |
|---|---|---|
| 报表口径 | 取 `Typrep='A'`（合并报表） | 99.9% 的 (股票, 报告期) 键有 A 口径 |
| 剔除期初行 | 丢弃 `Accper` 月份为 `01` 的行（**77,435 行**） | 其中 83.3% 数值与上年 12-31 完全相同，属"期初余额" |
| 披露时点 | 用 `IAR_Rept.Annodt` 而非报表的 `DeclareDate` | `Annodt` 零缺失；`DeclareDate` 是"会计差错更正日"且缺 92%+ |
| as-of 匹配 | 对每个 (股票, 月末) 取 `annodt ≤ 月末` 的**最后一条**年报 | 不等值连接，非等值 join |
| 单位 | `ME = Msmvttl × 1000` | 市值千元 → 元，与报表对齐 |

**实测覆盖率**（能匹配到年报的股票-月占比）：2000 年 91.8%、2010 年 91.2%、2020 年 94.8%、2025 年 99.0%。
**报表陈旧度**：报告期末到使用月份中位 **9.95 个月**（p10 4.9 / p90 14.9）——只用年报的必然结果。

### 3.2 L2：选样与特征

**过滤顺序与剔除量**（起始月 2000-01，共 915,674 行 → 保留 **740,221** 行 / 80.8%）：

| 顺序 | 原因码 | 剔除行数 | 规则 |
|---:|---|---:|---|
| 1 | `before_start` | 40,749 | `Trdmnt < 2000-01` |
| 2 | `no_t_minus_1` | 9,424 | 前一月无观测，无法形成 t−1 特征 |
| 3 | `no_return` | — | `Mretwd` 缺失（各股上市首月） |
| 4 | `bse` | 13,429 | `Markettype = 64`（北交所） |
| 5 | `financial` | 24,392 | `Indcd = 0001`（金融业） |
| 6 | `new_listing` | 54,033 | 面板内首现月份 < 12 个月 |
| 7 | `st` | 32,382 | 月末 `Trdsta ∈ {2,3,5,6,8,9,11,12,14,15}` |
| 8 | `pt` | 195 | 月末 `Trdsta = 16` |
| 9 | `negative_book_equity` | 849 | 账面权益 ≤ 0 |
| 10 | `nonpositive_me` | — | `me_lag ≤ 0` |
| 11 | `no_rf` | — | 无风险利率缺失 |

**收益口径**：`ret_ex = Mretwd − Nrrmtdt/100`；月内 1%/99% 缩尾（最大绝对值 **10.83 → 1.0099**）。
**权重**：`me_lag` = t−1 月末总市值（元）。
**时间对齐**：特征与权重取 **t−1 月末**，收益取 **t 月**。

**样本结果**：5,327 只、321 个月（2000-01 ~ 2026-09）、每月最少 **745** 只（中位 2,108）。

### 3.3 L3：编码

每月每特征 `2 × rank(pct) − 1` ∈ [−1, 1]；缺失填 **0**（等价于论文"填 0.5"再映射）；
`id`/`t` 重编为 0 基连续整数。

## 4. 口径决策清单（审查重点）

| # | 决策 | 取值 | 理由 | 替代方案 / 风险 |
|---|---|---|---|---|
| 1 | 起始月 | **2000-01** | 月横截面 < 200 只时 10 叶跑不动（代码逐月检查 `min_leaf_size`） | 1998 是下限（月最少 720 只）；用 1995 会让分裂大面积失败 |
| 2 | 上市满 12 月 | 用**面板内首现月份**，不用 `Listdt` | 17 只 `Listdt = 0000-00-00` 非法 | 用 `Listdt` 会把异常值带进来 |
| 3 | ST 判定 | **月末最后一天**的 `Trdsta`，不是"当月任一天" | 与建仓时点一致 | 用"任一天"会多删 906 个股票月（月内已摘帽的） |
| 4 | 北交所 | 剔除 `Markettype=64` | 交易规则、流动性不同 | 保留则需单独处理涨跌幅 30% |
| 5 | 金融业 | 剔除 `Indcd=0001` | 手册明确 `A001100000`（流动资产）"金融企业除外"，ATO/GMA 无意义 | — |
| 6 | 缺失填 0 | 排名后填 0 | 论文填 0.5 在 [0,1] 上，映射后即 0 | **副作用见 P1-2**：高缺失特征会被"有没有数据"主导 |
| 7 | 缩尾范围 | 在**合格样本的月内**做 | 与最终参与估计的样本一致 | 在全体样本上做会引入未参与估计的观测 |
| 8 | 因子口径 | 日 `P9714 RiskPremium1`；月 `P9714 Portfolios=1` | 沪深 A + 创业板 + 科创板，与样本口径一致 | 含北交所的 `P9719` 与样本不符 |
| 9 | 无风险利率 | `NRI01`（一年期定存）/12 | 表里只有这一个序列 | **与 FF 因子内置的三个月定存不一致**，见 P1-5 |
| 10 | 动量窗口 | 跳过最近 2 个月：`MOM6M` = τ−6..τ−2，`MOM12M` = τ−12..τ−2 | 对应论文"2–6 月""2–12 月"的字面表述 | 若原文是"跳过 1 个月"，定义需改 |
| 11 | 单因子设定 | `Z = 一列 1`、`H = 一列 0`、`no_H = TRUE` | 复现 demo1 的基础形态 | 见 P0-2：这意味着回归里**没有截距 α** |

合计贡献 2,118,000 个缺失单元格 = 全部缺失的 **50.1%**。

**逐年看是断崖**：

| 年份 | 长期借款缺 | 应付债券缺 | **总负债缺** | NOA 缺 |
|---|---:|---:|---:|---:|
| 2015 | 5.3% | 5.4% | 5.2% | 0.0% |
| 2016 | 4.5% | 4.7% | 4.1% | 0.0% |
| 2017 | 38.9% | 59.6% | 7.5% | **52.0%** |
| 2018 | 48.9% | 79.6% | 3.6% | **82.3%** |
| 2024 | 45.0% | 83.8% | **1.6%** | **87.6%** |

**诊断**：报表本身在（总负债只缺 1.6%），是"长期借款""应付债券"等**具体行次大面积空白**
（2017–2018 年新金融工具/新收入/新租赁准则改列报）。而代码里：

```python
int_debt = STDEBT + LTDEBT + BOND      # NaN + 2e9 = NaN，一个空白传染整行
NOA = (TA - CASH) - (TL - int_debt)
```

**后果最严重的地方**：训练期（2000–2015）这五项缺失 0%–5%，测试期（2016–2026）缺失
82%–91%。树若在训练期选中它们，到测试期等于按"缺失/不缺失"分组，而不是按 NOA 高低。

**建议修法**（尚未实施）：总负债存在时，把空白借款/债券行次视为 0。

```python
has_tl = TL.notna()
int_debt = (STDEBT.fillna(0) + LTDEBT.fillna(0) + BOND.fillna(0)).where(has_tl)
```

预计五项缺失降到 2%–6%，全表缺失率从 11.89% 降到约 7%。
**假设**："空白 = 该企业没有该项目"。需在论文中声明。

### P0-2　切分准则与论文不一致：代码最小化 SSR，论文最大化 SR²

- `src/common.cpp:61` 的 `fastLm` 返回 **OLS 残差平方和**；
- `src/APTreeModel.cpp:443` 用它作为分裂准则；
- 论文正文公式 (4) 是最大化因子 SR²。

**影响**：即使数据完全正确，长出的树也可能与论文不同。这是"代码 vs 论文"的已知差异，
不是本次数据处理的 bug，但审查时需要确认这是有意接受还是需要另行实现 SR² 准则。

**附带问题**：`no_H=TRUE` 时回归矩阵只有 `Z*ft`，即 `r = b0·f`，**没有独立截距 α**。
若要"定价误差含 α"的口径，需 `no_H=FALSE` 且 `H` 传一列常数 1。

### P1-1　四项特征的公式未经原文核对

论文 Table A.1 只给一行简述，以下四项是本次实现选定的口径，**未与原文附录核对**：

| 特征 | 本次实现 | 风险 |
|---|---|---|
| `OP` | 营业利润 / **股东权益** | 若原文分母是营收，则完全不同的变量 |
| `GRLTNOA` | `(NOA_τ − NOA_{τ−12}) / |NOA_{τ−12}|`（整体 NOA） | 原文写"长期"净经营资产，未给拆分方式 |
| `CHCSHO` | 股本变动率，**未做拆股/送转调整** | 送转股会被误读为"股本大幅增加" |
| `NI` | 吸收投资收到的现金 / 市值 | 原文"净股权发行"可能指股本变动口径 |

### P1-2　缺失填 0 的副作用

48 项中有 6 项缺失 >50%（ABR 91.9%、LGR 70.8%、GRLTNOA 56.4%、CASHDEBT 56.2%、
RNA 51.4%、NOA 51.4%）。填 0 在排名尺度上是"中性"，但这些行实际占多数，
树可能学到的是**"该股票有没有这项数据"**而不是特征的横截面高低。

**完整的观测（48 项全有）只占 1.01%**；剔除 ABR 后 12.76%；只看 39 项核心特征则 31.7%，
核心组缺失率 4.59%。审查时需判断这个处理是否可接受。

### P1-3　无风险利率口径与 FF 因子不一致

用 `NRI01`（一年期整存整取）；CSMAR 因子内置的是**三个月定存**。
计算超额收益与做 FF 回归时**不能重复减**，且两者基准不同。已在文档中声明，但这是实质性差异。

### P1-4　季频特征的单季还原

中国利润表是**年初至今累计**，代码按 `Q1 = cum, Q2 = cum−Q1, Q3 = cum−Q2, Q4 = cum−Q3`
还原单季，并要求相邻季度连续（`qidx` 差为 1），否则置缺失。
2002 年前多为半年报，SUE/NINCR/RSUP 自然缺失（实测 14%–16% 缺失）。
**需审查**：`qidx = year*4 + (month//3 − 1)` 的季度编号与"连续"判断是否正确。

### P1-5　ABR 是事件型特征，92% 缺失属设计使然

只在年报公告月有值（60,162 / 740,221 = 8.1%）。
事件窗是 `[−1, +1]` 交易日、市场调整。若要当普通特征用，需改成"最近一次公告的 CAR"连续化，
否则建议单列或剔除。

### P2-1　BASPREAD 只能用高低价代理

CSMAR 日行情没有买卖报价，只有最高/最低价。用 Corwin–Schultz (2012) 估计，
存在已知的向上偏差。实测中位 0.0085。

### P2-2　DY（股息率）已撤下

原方案认为 `DY = (1+Mretwd)/(1+Mretnd) − 1`。实测两序列**都含现金红利**，
只差"红利再投资还是持有现金"，二者之差 ≈ 红利 × 除息后涨跌，量级 0.02% 且正负各半
（工商银行 2018-07 股息率≈5%，两者只差 0.22%）。因此 DY 需要"分红送转"表才能构造。

### P2-3　行业分类只有当前值

`TRD_Co` 的 `Indcd`/`Nindcd`/`Nnindcd` 都是**当前**分类，没有历史。
因此 BMIA / MEIA / HERF 三项未实现（用当前行业会有前视）。

### P2-4　四项无源字段

`ADM`（广告费并入销售费用 `B001209000`）、`DEPR`（直接法现金流无折旧项）、
`HIRE`（无员工人数）、`RE`（无分析师数据）。其中 `DEPR` 只要补下载**间接法现金流表
`FS_Comscfi`** 即可解决。

### P2-5　其余已知限制

| 项 | 说明 |
|---|---|
| 2007 年会计准则变更 | 截面排名可吸收共同水平位移，但若改用水平值回归必须加哑变量 |
| ST 识别起点 | `Trdsta` 在 1997 年及以前全为 1，**1998-04** 才首次出现 ST；早期样本的 ST 过滤是空操作 |
| 停牌月 | 整月停牌直接不出现在月表里（35.9% 的股票存在中间缺月），未用 0 填补；长窗口特征因此缺失 |
| 退市股票 | 保留退市前记录，但**未显式处理退市月收益**（CSMAR `Mretwd` 是否含退市补偿未核实） |
| 报表版本 | 只能用"最后一次公告的修正后数值"，真正的 point-in-time 需要历史版本库 |
| 中文路径 | R 对非 ASCII 库路径不可靠，因此 R 包编译/安装在 `C:\Users\lenovo\R\`，数据处理仍在工作区 |

## 8. 建议审查的重点（按优先级）

1. **P0-1 的修法**：把空白借款/债券当 0 是否成立？会不会在某类公司（金融、房地产）引入偏差？
   有没有更稳妥的做法（按行业分别处理、或用总负债倒挤）？
2. **P0-2**：切分准则用 SSR 而非 SR²，是否接受？若要实现 SR²，是改 C++ 还是先用 SSR 跑通再替换？
3. **`no_H=TRUE` 无截距**：`r = b0·f` 的设定是否会让树的评价偏离论文？
4. **缺失填 0**：48 项中 6 项 >50% 缺失，是否应改为"剔除该特征"或"用行业中位数填"？
5. **四项未核对公式（P1-1）**：`OP` 分母、`GRLTNOA` 的"长期"、`CHCSHO` 拆股、`NI` 口径。
6. **季频单季还原**：`qidx` 连续判断与 Q4 = 年报 − Q3 累计是否正确。
7. **日频窗口**：3 个月、最少 30 个交易日、`RVARFF3` 用伪逆，是否合理。
8. **缩尾在合格样本上做**：是否引入了选择偏差（先过滤后缩尾）。
9. **未来函数**：除已核对的 t−1 对齐外，是否还有地方用到当期不可得信息
   （重点看 `features_annual.py` 的 12 个月滞后与前缀、`features_quarterly.py` 的 as-of）。
10. **`min_leaf_size` 逐月检查**：代码对"每个子叶在每个月"都要 ≥20 只，
    这会造成样本选择（每月只有 745 只时，某些分裂被系统性排除）。

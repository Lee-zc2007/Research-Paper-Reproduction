### 生效处理规则

1. 资产有限且为正、负债和现金有限且非负、权益有限时，将短期借款、长期借款、应付债券空白按结构性零处理。其余报表缺失保持缺失。该假设未经数据供应商确认，不能宣称空白已证实等于零。
2. CASHDEBT仍要求有息负债大于零。LGR仍要求12个月前长期借款加债券大于零。零分母保持缺失，不通过填零伪造比率。
3. 季度计算先补齐每只股票的季度日历，再按8个日历季度滚动，最少4个有效观察。公告记录按季度及Reptyp对应筛选。插入的空季度不参与公告日as-of。
4. BASPREAD改为当前日与前一交易观测配对，消除原先shift(-1)使用下一日价格的问题。文件批次边界不跨文件配对，边界覆盖限制仍存在。
5. ABR要求完整三个交易日，按事件窗口最后交易日所属月记录可用时点，之后由主表统一滞后一月。仍为稀疏事件特征，不进入覆盖候选；批次边界不完整窗口舍弃。
6. 动量保留完整窗口规则，不把停牌缺月擅自当作零收益。财务增长保留12个月历史要求。NI空白保持缺失。
7. audit_stage4按股票与报告期保留最后一次公告，与生产规则对齐。
8. 从原始数据重新生成L1，使用--refresh刷新年频、季频、日频及日频汇总缓存，再导出排名输入与RDS。

## 历史方案与定义记录


> 论文 Table A.1 共 61 项。本文档记录**已实现的 48 项**的精确公式、源字段、实测覆盖率
> 与已知局限，以及**未实现的 13 项**及原因。
> 所有特征都在 **τ 月末（特征月）** 计算；`build_monthly_panel.py` 再把它们整体
> 下移一个月，与 t 月收益配对。因此"行 (i, t)"里的特征是 (i, t−1) 的值。

## 一、口径约定

| 项 | 约定 |
|---|---|
| 报表口径 | `Typrep = 'A'`（合并报表）；剔除 `Accper` 月份为 `01` 的期初行 |
| 披露时点 | `IAR_Rept.Annodt` 做 as-of（`Annodt ≤ 月末`）；不用 `DeclareDate` |
| 金额单位 | 报表为**元**，`Msmvttl` 为**千元**，统一乘 1000 后再相除 |
| 因子单位 | CSMAR 三/五因子**已是小数**（2020 年 `RiskPremium1` 的 std = 0.0135），**不要除 100** |
| 累计转单季 | 利润表是年初至今累计，必须先还原单季（Q4 = 年报 − Q3 累计） |
| 缺失 | L2 保留缺失；L3 排名后填 **0**（等价于论文的 0.5） |
| 极值 | 收益做月内 1%/99% 缩尾；特征不缩尾，靠横截面排名吸收 |

## 四、C 组：日频（11 项，`features_daily.py`）

窗口统一为**截至 τ 月末的过去 3 个月**，用月度充分统计量做滚动求和；窗口内至少 30 个交易日。
超额收益 = `Dretwd − Nrrdaydt/100`；市场 = `RiskPremium1`（`P9714`，已是小数）。

| 特征 | 公式 | 缺失 |
|---|---|---:|
| SVAR | 日超额收益方差 | 0.72% |
| BETA | `Cov(r, m) / Var(m)` | 0.72% |
| RVARCAPM | `Var(r) − BETA² · Var(m)` | 0.72% |
| RVARFF3 | `r = a + b₁mkt + b₂smb + b₃hml` 的残差方差（伪逆求解） | 0.72% |
| ILL | `mean(|r| / 成交额(元)) × 1e6`（Amihud） | 0.72% |
| MAXRET | 窗口内最大日超额收益 | 0.72% |
| ZEROTRADE | `1 − 该股交易日数 / 市场交易日数` | 0.72% |
| STDTURN | 日换手率标准差 | 0.72% |
| STDDOLVOL | `ln(成交额)` 标准差 | 0.72% |
| BASPREAD | Corwin–Schultz 月内相邻日配对后平均 | 0.72% |
| ABR | 年报公告日 `[−1,+1]` 的市场调整累计异常收益，归入公告月 | 91.87% |

**方向性校验**（与 `lnME` 的秩相关）：`ILL −0.781`、`DOLVOL +0.684`、`ZEROTRADE −0.128`，
小盘股更不流动、成交额更小、零成交更多——符号与量级都符合预期。
`BETA` 中位 1.15（p10 0.57 / p90 1.79）；`SVAR` 在 2008、2015 明显走高。

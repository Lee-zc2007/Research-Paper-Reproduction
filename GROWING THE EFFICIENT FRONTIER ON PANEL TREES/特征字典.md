# 特征字典（L2 输出，48 项）

> 论文 Table A.1 共 61 项。本文档记录**已实现的 48 项**的精确公式、源字段、实测覆盖率
> 与已知局限，以及**未实现的 13 项**及原因。
> 所有特征都在 **τ 月末（特征月）** 计算；`build_monthly_panel.py` 再把它们整体
> 下移一个月，与 t 月收益配对。因此"行 (i, t)"里的特征是 (i, t−1) 的值。

## 一、口径约定

| 项 | 约定 |
|---|---|
| 报表口径 | `Typrep = 'A'`（合并报表）；剔除 `Accper` 月份为 `01` 的期初行 |
| 披露时点 | `IAR_Rept.Annodt` 做 as-of（`Annodt ≤ 月末`）；不用 `DeclareDate` |
| 金额单位 | 报表为**元**，`Msmvttl` 为**千元**，统一乘 1000 后再相除 |
| 因子单位 | CSMAR 三/五因子**已是小数**（2020 年 `RiskPremium1` 的 std = 0.0135），**不要除 100** |
| 累计转单季 | 利润表是年初至今累计，必须先还原单季（Q4 = 年报 − Q3 累计） |
| 缺失 | L2 保留缺失；L3 排名后填 **0**（等价于论文的 0.5） |
| 极值 | 收益做月内 1%/99% 缩尾；特征不缩尾，靠横截面排名吸收 |

## 三、B 组：季频（4 项，`features_quarterly.py`）

| 特征 | 公式 | 缺失 |
|---|---|---:|

## 四、C 组：日频（11 项，`features_daily.py`）

窗口统一为**截至 τ 月末的过去 3 个月**，用月度充分统计量做滚动求和；窗口内至少 30 个交易日。
超额收益 = `Dretwd − Nrrdaydt/100`；市场 = `RiskPremium1`（`P9714`，已是小数）。

| 特征 | 公式 | 缺失 |
|---|---|---:|
| SVAR | 日超额收益方差 | 0.7% |
| BETA | `Cov(r, m) / Var(m)` | 0.7% |
| RVARCAPM | `Var(r) − BETA² · Var(m)` | 0.7% |
| RVARFF3 | `r = a + b₁mkt + b₂smb + b₃hml` 的残差方差（伪逆求解） | 0.7% |
| ILL | `mean(|r| / 成交额(元)) × 1e6`（Amihud） | 0.7% |
| MAXRET | 窗口内最大日超额收益 | 0.7% |
| ZEROTRADE | `1 − 该股交易日数 / 市场交易日数` | 0.7% |
| STDTURN | 日换手率标准差 | 0.7% |
| STDDOLVOL | `ln(成交额)` 标准差 | 0.7% |
| BASPREAD | Corwin–Schultz 月内相邻日配对后平均 | 0.7% |
| ABR | 年报公告日 `[−1,+1]` 的市场调整累计异常收益，归入公告月 | 91.9%（事件型） |

**方向性校验**（与 `lnME` 的秩相关）：`ILL −0.781`、`DOLVOL +0.684`、`ZEROTRADE −0.128`，
小盘股更不流动、成交额更小、零成交更多——符号与量级都符合预期。
`BETA` 中位 1.15（p10 0.57 / p90 1.79）；`SVAR` 在 2008、2015 明显走高。

## 五、⚠ 已知口径不确定性

| 项 | 问题 | 影响 |
|---|---|---|
| OP | 分母用权益（`B001300000/A003000000`） | 论文表述含糊，若应为营收则需改 |
| GRLTNOA | 论文写"长期净经营资产"，未给拆分公式 | 用了整体 NOA 的增长 |
| CHCSHO | 未做拆股/送转调整 | 送转股会被误读为"股本大幅变动" |
| NI | 用"吸收投资收到的现金/市值"作代理 | 不是严格的股本变动口径 |

**根本限制**：论文 Table A.1 只给一行简述，上述四处的确切公式需按原文附录核对。
本文档记录的是**本次实现采用的定义**，不是"已确认等于论文"。

## 六、未实现的 13 项

| 特征 | 原因 | 能否补救 |
|---|---|---|
| **DY** | `Mretwd` 与 `Mretnd` **都含现金红利**，只差"是否再投资"，二者之差 ≈ 红利 × 除息后涨跌，量级 0.02% 且正负各半（工行 2018-07 股息率≈5%，两者只差 0.22%） | 需"分红送转"表 |
| ALM | Table A.1 只写"季度资产流动性"，无公式 | 需查原文附录 |
| PS | "业绩评分"，需自定合成方式 | 需查原文附录 |
| SEAS1A | "1 年季节性"，定义不明 | 需查原文附录 |
| BMIA / MEIA / HERF | 需**历史**行业分类，现有只有当前分类 | 需下载历史行业表 |
| RDSALE / RDM | `B001216000` 2016 年才有值、缺 59% | 需"研发投入"专项表 |
| ADM | 广告费并入 `B001209000` 销售费用 | 需年报附注或广告费专表 |
| DEPR | 直接法现金流表无折旧项 | 需下载**间接法**现金流表 |
| HIRE | 无员工人数 | 需员工构成表 |
| RE | 无分析师预测数据 | 需分析师预测库 |

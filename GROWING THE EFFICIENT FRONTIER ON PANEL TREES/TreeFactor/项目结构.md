# TreeFactor 项目结构

## 1. 项目概述

本项目是面板树资产定价模型（Panel Tree Factor Model）的 R 包，包名为 `TreeFactor`。R 层负责数据处理、模型调用与实验流程，C++ 层负责树生长、分裂准则评估、叶节点组合构建及因子计算。

根据 `DESCRIPTION`，包版本为 `1.0`，声明日期为 `2022-02-09`，依赖 `Rcpp`，编译链接依赖 `Rcpp` 与 `RcppArmadillo`，需要编译 C++ 源码。

本文根据当前仓库文件及源码静态阅读整理，未编译或运行实验。

## 3. 主要模块职责

### 3.1 R 接口层

| 文件 | 主要职责 |
|---|---|
| `R/TreeFactor_APTree.R` | 转换输入矩阵，通过 `.Call` 调用基础模型 C++ 入口，并将返回对象标记为 `APTree` 类。 |
| `R/TreeFactor_APTree_2.R` | 调用带时间序列分裂的训练入口，支持首层分裂点以及不同层的候选分裂变量。 |
| `R/predict.APTree.R` | 调用 C++ 确定样本叶节点，在 R 中按时期和叶节点汇总加权收益，再以训练所得叶组合权重合成因子。 |
| `R/RcppExports.R` | Rcpp 自动生成的底层调用封装。 |
| `R/leaf_regression.R` | 叶节点回归封装；其调用的 C++ 函数在当前仓库中未找到实现或注册。 |

### 3.2 C++ 核心层

核心训练链路由以下模块组成：

1. `TreeFactor_APTree.cpp` 或 `TreeFactor_APTree_2.cpp`：接收 R 传入的数据和参数，初始化训练状态及树，组织训练并返回结果。
2. `state.h`：保存训练数据引用、参数及中间状态。
3. `APTree.h`、`APTree.cpp`：管理树节点、父子关系、叶节点遍历及树生长过程。
4. `model.h`、`APTreeModel.cpp`：检查节点是否可分裂，评估候选分裂，计算叶组合收益、组合权重、因子与拟合指标。
5. `predict_APTree.cpp`：根据保存的树结构，把新样本分配到叶节点。
6. `json_io.h`、`json_io.cpp`：提供树结构的 JSON 序列化支持。

`APTreeModel.cpp` 是理解模型算法的重点文件，包含 `calculate_criterion`、`calculate_criterion_one_variable`、`calculate_factor` 和 `calculate_R2` 等方法。

## 4. 数据与实验

### 4.1 模拟数据

`data/simulate_data.r` 设置了 1,000 个资产、100 个时期，模拟资产收益、5 个个体特征、2 个宏观变量和市场因子。

脚本保存的对象包括：

| 对象 | 内容 |
|---|---|
| `da` | 面板数据，包含 `xret`、`id`、`date`、`mkt`、`m1`、`m2`、`c1` 至 `c5`。 |
| `f` | 市场因子矩阵。 |
| `xt` | 宏观变量矩阵。 |
| `beta` | 模拟市场暴露矩阵。 |

脚本将结果保存为工作目录下的 `simu_data.rda`；按照 `demo.sh` 的流程在 `data/` 中执行时，输出为 `data/simu_data.rda`。

### 4.2 三个 Demo

| 示例 | 入口 | 实验内容 |
|---|---|---|
| Demo1 | `test/demo1/main.R` | 先训练基础树，再以第一阶段残差为目标训练第二棵树，并计算测试期因子。 |
| Demo2 | `test/demo2/main_mkt_adj.R` | 先通过市场因子回归获得残差，再训练面板树。 |
| Demo3 | `test/demo3/main_ts.R` | 使用宏观变量及市场因子作为首层候选分裂变量，演示时间序列分裂。 |

三个 Demo 均设置前 80 期为训练区间、后 20 期为测试区间；Demo3 当前脚本主要展示训练及首层分裂结果。

`test/` 主要存放演示脚本和已有输出日志，未看到规范的自动化单元测试。已有日志不能作为当前版本成功运行的证明。

## 5. 运行与调用关系

```text
data/simulate_data.r
        ↓
data/simu_data.rda
        ↓
Demo 脚本：整理变量、划分训练集和测试集
        ↓
R/TreeFactor_APTree.R 或 R/TreeFactor_APTree_2.R
        ↓ .Call
C++ 训练入口
        ↓
State：保存数据与参数
        ↓
APTree：组织树生长
        ↓
APTreeModel：评估分裂、构建叶组合、计算因子
        ↓
返回 APTree 对象
        ↓
predict()：分配新样本 → 计算叶组合收益 → 合成因子收益
```

基础模型的主要返回字段如下：

| 字段 | 含义 |
|---|---|
| `tree` / `json` | 树的文本表示及 JSON 序列化结构。 |
| `leaf_id` | 叶节点编号。 |
| `portfolio` | 各叶节点组合的收益序列。 |
| `leaf_weight` | 合成因子的叶组合权重。 |
| `ft` | 因子收益序列。 |
| `R2` | 模型拟合指标。 |
| `all_criterion` | 基础模型训练过程中记录的候选分裂准则。 |

`predict()` 需要输入新样本的实际收益 `R`，用于构建组合收益与因子序列，并非仅根据特征预测未来收益。

## 6. 当前版本需要注意的问题

以下问题来自静态阅读，尚未通过运行验证或修复。

1. **Demo1、Demo2 与当前基础训练接口存在位置参数错位。** 示例在 `num_cutpoints` 后传入 `lambda, eta, equal_weight, ...`，当前 `TreeFactor_APTree()` 接口在该位置接收的是 `eta, equal_weight, no_H, ...`，正则化参数为末尾的 `lambda_mean` 和 `lambda_cov`。直接运行会导致参数按错误位置绑定，复现实验前应核对并改用具名参数。
2. **当前目录未包含生成好的 `data/simu_data.rda`。** Demo 依赖该文件，需要先执行模拟脚本。
3. **叶节点回归接口疑似为遗留代码。** `R/leaf_regression.R` 调用 `leaf_regression_cpp()`，当前仓库未找到其实现或注册。
4. **Demo 有额外依赖。** 示例加载 `rpart` 和 `ranger`，但 `DESCRIPTION` 未声明这两个包。
5. **帮助文档不完整。** `man/TreeFactor-package.Rd` 仍包含模板占位内容，使用细节需结合源码和 Demo 理解。
6. **编译配置需要结合本机环境核对。** `Makevars` 与 `Makevars.win` 配置了 C++11、BLAS/LAPACK、OpenMP 和 `ccache` 相关选项；本文尚未验证本机编译环境。

## 7. 建议阅读顺序

1. `README.md`、`DESCRIPTION`：了解项目定位、安装方式及依赖。
2. `data/simulate_data.r`：理解模拟数据及变量含义。
3. `test/demo1/main.R`：理解训练、残差 boosting 与测试期因子计算。
4. `R/TreeFactor_APTree.R`：确认当前参数定义及调用方式。
5. `src/TreeFactor_APTree.cpp`：理解 C++ 训练流程。
6. `src/APTree.cpp`、`src/APTreeModel.cpp`：深入树生长与全局分裂准则。
7. `R/predict.APTree.R`、`src/predict_APTree.cpp`：理解预测阶段的叶节点分配和组合计算。
8. `test/demo2/main_mkt_adj.R`、`test/demo3/main_ts.R`：进一步理解市场调整与时间序列分裂扩展。

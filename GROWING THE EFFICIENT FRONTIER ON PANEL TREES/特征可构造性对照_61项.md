# 论文 61 项特征 × 现有数据 可构造性对照

> 依据：论文 Table A.1（从本地 PDF 提取，共 61 项）；数据：`raw_data` 现有表。
> 判定说明：✅ 直接可构造；🟡 需历史行业（可用当前行业近似）；🔵 依赖日频行情（2010-01～2021-10 缺）；❌ 本目录没有源字段。

## 一、汇总

| 判定 | 项数 | 含义 |
|---|---:|---|
| ✅ 直接可构造 | **41** | 用月频行情 + 三张报表 + 公告日即可 |
| 🟡 需历史行业（可近似） | **3** | BMIA、MEIA、HERF；用当前行业近似会有轻微前视 |
| 🔵 依赖日频 | **11** | 1991–2009 可算；2010-01～2021-10 不可算 |
| ❌ 本目录无源 | **6** | ADM、DEPR、HIRE、RE、RDSALE、RDM |
| 合计 | **61** | |

由此得到"数据条件 → 可用特征数"的阶梯：

| 数据条件 | 可用项 | 占 61 项 |
|---|---:|---:|
| 现有数据（含当前行业近似） | **44** | 72% |
| 现有数据 + 补 2010–2021 日行情 | **55** | 90% |
| 再补研发 / 员工 / 广告 / 折旧 / 分析师数据 | **61** | 100% |

> 样本从 2000 年起时，44 项全部可用；若样本从 1995 年起，ACC/CFP/CINVEST/PCTACC 需 1997 年后（现金流表起点），SUE/NINCR/RSUP 需 2002 年后才有完整季报。
> 补日行情后的 55 项中，BASPREAD 仍只能用高低价代理（CSMAR 日行情没有买卖报价），其余 10 项可严格计算。

## 三、对论文"最常用分裂特征"的影响

论文表 6（random P-Forest 的选择概率）给出的高频特征共 8 个：

| 出现位置 | 特征 | 本数据状态 |
|---|---|---|
| Top1（0.51）、Top2（0.66）、Top3（0.71） | SUE | ✅ |
| Top1（0.34）、Top2（0.38）、Top3（0.41） | SVAR | 🔵 日频缺 |
| Top1（0.25）、Top2（0.31） | CHPM | ✅ |
| Top1（0.23） | RVARCAPM | 🔵 日频缺 |
| Top1（0.21） | BASPREAD | 🔵 无报价，只能高低价代理 |
| Top2（0.34）、Top3（0.53） | DOLVOL | ✅ |
| Top2（0.31）、Top3（0.48） | BMIA | 🟡 需行业 |
| Top3（0.41） | MEIA | 🟡 需行业 |

结论：**日频缺口打击的不是边角特征，而是 Table 6 里排在最前的 SVAR、RVARCAPM、BASPREAD**；同属日频类的 ZEROTRADE、MAXRET、ILL、BETA 也一并受影响。行业缺口则正好影响 BMIA、MEIA——两者都进了 Top3。若只做"月频 + 会计"版本，能被稳定选中的高频特征主要是 **SUE、DOLVOL、CHPM**（以及次高频的 BM、ME、ROA、OP）。
